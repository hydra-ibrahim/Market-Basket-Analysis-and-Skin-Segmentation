Market Basket Analysis and Skin Segmentation

A Django REST API combining two independent ML pipelines: an Apriori-based product recommendation engine, and a k-Nearest Neighbours skin-pixel classifier. Source and full write-up on GitHub.

Skin-pixel classifier

Upload a photo, click a pixel, and a k-NN model classifies it as skin or not — live, in the browser.

Related-products engine
